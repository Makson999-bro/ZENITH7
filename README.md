# Zenith Client (Fabric 1.20.4)
Menu: Right Shift | Zoom: hold C

Build: install JDK 17 + Gradle 8.5, run build.bat (Windows) or build.sh.
Result: build/libs/zenith-client-1.0.0.jar -> put into .minecraft/mods (needs Fabric Loader + Fabric API 1.20.4).
No local setup? Push this folder to GitHub: Actions builds the jar automatically (Artifacts).
